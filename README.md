# Kalkülatör — Android Güncellemeleri

Bu depo yalnızca son kullanıcıya dağıtılan APK sürüm paketleri ile HTTPS güncelleme manifestini barındırmak için hazırlanmıştır.

Kaynak kodlar, imza anahtarları, eşleştirme dosyaları ve özel veriler bu depoya yüklenmez.

Şu andaki latest.json durum kodu DRAFT_DO_NOT_PUBLISH: uygulama bunu gerçek güncelleme olarak kabul etmeyecek.

APK dosyaları GitHub Releases altında yayımlanmalıdır; kaynak commitlerine eklenmemelidir.

Güncelleme manifesti: https://raw.githubusercontent.com/wexnap/kalkulator-updates/main/latest.json

Yayın öncesinde APK'nin HTTPS üzerinden indirilebilir olduğu, SHA-256 ve imza uyumu doğrulanmalıdır. Test imzası, üretim anahtarıyla değiştirilmeden genel dağıtım için önerilmez.
